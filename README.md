# HR Training Simulator 0.7.4

macOS: Node.js 22 이상을 설치하고 이 폴더에서 아래 명령을 실행합니다.

```sh
npm ci
npm run dev
```

초록색 실행 안내는 제거했습니다. 상단의 작은 Build 표기와 브라우저 제목에서 0.7.4를 확인할 수 있습니다. 기본 주소는 http://127.0.0.1:5173 입니다. `.command` 실행파일은 포함하지 않습니다.

5173을 알 수 없는 다른 프로그램이 사용하면 실행을 중단합니다. 해당 프로그램을 직접 종료하거나, 별도 테스트 환경을 열 때만 `HR_PORT=5184 npm run dev`를 사용할 수 있습니다. **브라우저의 IndexedDB는 주소·포트별로 분리됩니다. 기존 데이터는 이전과 같은 브라우저와 주소·포트에서 열어야 합니다.**

화면을 열 때는 `npm run dev`를 실행합니다. `npm run build`는 배포 파일을 생성하는 검증 명령입니다.

## 근태 및 급여 파일

- 근태 화면 오른쪽 위: 샘플데이터 다운받기 / 데이터 내보내기 / 가져오기.
- CSV·XLSX·JSON은 공통 한글 열로 왕복 입력합니다. 다운로드한 사번·귀속월을 유지하고 숫자만 수정하세요. 사번·기간 중복이나 잘못된 숫자가 있으면 전체 저장을 중단합니다.
- 근태의 `근태 내보내기`는 현재 필터에 보이는 행만 같은 열 순서로 출력합니다. 상단 `데이터 내보내기`는 전체 근태입니다.
- 급여 입력·조회·엑셀·개인 상세는 같은 열 목록과 순서를 사용합니다. 사번·귀속월·성명을 유지하고 파란색 입력 항목과 메모를 수정한 뒤 해당 급여월에서 업로드하세요. 조회 보고서도 같은 월의 입력값을 다시 업로드할 수 있습니다. 급여 조회의 업로드는 여러 월이 섞인 보고서도 개인·귀속월·지급일로 매칭하고 전체를 검증한 뒤 한 번에 반영합니다. 급여 입력의 업로드는 선택한 급여월 자료만 반영합니다.
- 월 기본급도 해당 급여월에서 수기 수정할 수 있습니다. 계산된 합계·보험료·상태 등은 조회값입니다. 보험·지방세 고지액은 전용 `수기` 열 또는 개인 입력창으로 적용합니다. 빈칸은 자동 계산, 0원은 명시적 0원 적용입니다. 파일의 계산 결과를 직접 바꿔도 입력으로 반영하지 않습니다. `소득세 입력`은 수기 입력값, `소득세`는 계산 결과입니다.
- 입력·조회에서 개인 행을 누르면 상세와 개인 다운로드가 열립니다. 입력 상세에서 `개인 수기 수정`을 누르거나 행의 `수기 수정`을 사용하세요. 체크박스로 대상자를 선택하고 `선택 N명 일괄 수정`으로 한 항목을 같은 값으로 변경하거나 더하고 뺄 수 있습니다. 저장 후 급여를 다시 계산하세요.
- 긴 급여 표는 세로 높이를 제한하고 헤더를 고정합니다. 가로 스크롤은 각 테이블 안에서 사용합니다. 화면 하단 고정 스크롤은 제거했습니다.
- 일용직 개인 근무기록에서 연장·야간·휴일·기타수당을 금액으로 입력합니다. 수당은 과세 지급액에 합산하고 원천세를 다시 계산합니다. 근로시간별 자동 가산금은 별도 산정 후 입력합니다. 기존 기록은 수당 0원으로 호환되며 저장 전까지 원본을 변경하지 않습니다.
- 일용직 목록과 근무·수당 목록도 JSON/XLSX/CSV로 내려받고 재업로드할 수 있습니다. 일용직 개인 내역은 표와 같은 순서로 다운로드하고 `수정 파일 업로드`로 반영합니다. 번호·성명·근무일을 유지하세요. 기존 시각 미등록 기록은 시간 합계를 수정할 수 있으며 가상의 시각을 생성하지 않습니다. 파일 전체 검증이 통과할 때만 한 번에 저장합니다.
- 근태 화면 밖의 상단 내보내기는 전체 DB 백업입니다. CSV·XLSX는 자료종류·번호·자료JSON 열로 관계와 값을 보존합니다. 전체 백업은 근태 화면 밖에서 가져옵니다.

## 근태 → 급여

수기 수정 사유·수정자·시각·차수를 저장합니다. 캘린더에서 출근·퇴근·익일 여부·휴게 구간을 입력하고 여러 날짜에 일괄 적용합니다. 기존 월 합계에서 가상의 출퇴근 시각을 생성하지 않습니다. 근태의 개별 수정 팝업에는 일별 출퇴근·휴게·휴가 구간이 함께 보입니다. `근태 일괄 수기 수정`에서는 조회된 여러 개인·월의 항목을 함께 정정할 수 있습니다. 캘린더는 `09:00~18:00 (8h)`로 표시하며 연차·휴무·병가와 근무 중 휴가 구간을 입력하면 휴게와 겹치는 시간을 중복 차감하지 않습니다. 모든 날짜를 입력한 뒤 `날짜별 합계를 월 근태에 적용`으로 월 합계를 교체하세요.

근태 또는 휴직 변경은 관련 급여월 결과와 검증을 해제합니다. 급여 입력에서 `근태 수당 반영` → 계산 → 검증을 진행하세요. 이 버튼의 통상시급은 월209시간 기준이며, 통상임금 포함 수당과 근무제도·주40시간 초과·주휴 등은 별도로 검토해야 합니다. 확정·마감월은 원자료 수정도 차단합니다.

## 연차 및 수기 정산

WFM 연차와 Payroll 연차는 같은 원장을 사용합니다. `연차 수기 입력` 팝업의 개별 적용·일괄 적용에서 발생·이월·조정·사용을 입력하며 잔여는 자동 계산합니다. 원장 추가도 같은 팝업에서 개인·연도를 고르고 입력할 수 있습니다. 캘린더의 연차시간과 연차 원장은 별도 적용입니다. 팀·입사일 등 열 간격은 12px 좌우 여백으로 통일하고 줄바꿈을 막았습니다.

퇴직정산·연말정산에 수기 입력·개인 수정·JSON/XLSX/CSV 다운로드·재입력을 연결했습니다. 수기 연말정산은 이후 자동 집계로 덮어쓰지 않습니다. 최종 소득세 입력 − 기납부 소득세로 정산액을 계산합니다. 확정된 정산은 수정할 수 없습니다. 파일·수기 값은 법정 계산의 자동 확정으로 취급하지 않습니다.

원천세 신고 자료의 개인 표는 급여 표와 같은 열을 사용합니다. 개인 상세에서 월 기본급·소득세·보험 기준·고지액을 수기 입력하고 급여 입력에서 재계산합니다. 원천징수이행상황신고자료 대사도 화면과 같은 열로 내보내고 수기·파일 정정을 저장합니다. 별도 집계 정정은 개인 급여를 변경하지 않습니다.

## 직원 필터

이름/사번 검색은 별도입니다. 재직상태·조직·직무·직급을 분류 드롭다운에서 먼저 선택하고 다음 드롭다운의 목록에서 검색·선택합니다. 여러 분류 조건을 함께 유지하며 선택된 조건은 아래 버튼으로 해제할 수 있습니다. 직원 목록에 퇴사일을 표시합니다. 대시보드에는 조회대상 개인 목록을 표시하지 않습니다.

## 급여 설정

설정 저장과 이전양식 복원은 확인창을 표시하고 수정일·감사로그를 남깁니다. 이전양식은 직전 저장본입니다. 일시 적용은 해당 급여월에 저장하며 검증 재계산에도 유지합니다. `급여계산 초기화`는 현재 급여 설정으로 해당 월을 재계산합니다. 마감월은 변경되지 않습니다.

## 휴직

휴직 유형·기간·회사 기본급 지급비율·연금 납부예외 승인·건보 고지유예/근로자 고지액·고용보험 신고보수·지원금·평균임금 제외 검토·연말정산 메모를 별도로 기록합니다. 기존 휴직 사유는 추정하지 않고 미확인으로 표시합니다. 등록된 기간은 급여에 반영되지만, 유형만으로 법정 지원금·보험 경감률을 자동 확정하지 않습니다. 중간 입복직 월 보험은 공단 고지와 별도 대사해야 합니다. 지원금은 회사 급여에 중복 합산하지 않습니다.

## 세무·법정 정산 범위

출력은 모두 한글 신고 입력·대사 자료입니다. **홈택스·공단 직접 업로드 파일이 아닙니다.** 실제 사업자번호·주민번호·기관별 전자신고 규격과 검증이 없는 가상 데이터이므로 직접 신고 가능하다고 표시하지 않습니다. 소득세는 국세청 간이세액표 확인 후 수동 입력입니다. 산재보험은 사용자 전액 부담·사업장별 요율을 확인합니다. 일용 소액부징수 계산은 일별 지급을 전제로 하며 합산 지급 시 다시 판정해야 합니다.

퇴직급여는 기존 월평균/30 가정의 검토용 추정이며 DRAFT로 저장합니다. 법정 확정에는 실제 3개월 달력일수·제외기간·상여3/12·연차수당 자료가 필요합니다. 연말정산은 계산된 급여의 연간 과세총액·기납부세액을 집계하며 최종 세액은 자동 확정하지 않습니다.

## 데이터·검증·배포

DB 이름 `hr-training-simulator` 유지. DB v6 / Schema v6 / Seed v5. 기존 데이터를 지우지 않고 v5→v6 마이그레이션합니다. 새 날짜별 근무·휴가 구간·연차 수기 이력·정산 입력·보험 및 신고대사 수기값·휴직·설정 복원 이력도 전체 백업에 포함합니다. `npm run verify:release`는 메뉴·버전 점검과 실제 마이그레이션·저장·계산·파일 왕복 및 UI 마크업 회귀검증을 실행합니다. dev/build 시작 전에 자동 실행합니다.

```sh
npm test
npm run build
```

GitHub Pages는 기존 `.github/workflows/deploy.yml`과 Vite `base: './'`를 유지합니다. main push 또는 workflow_dispatch에서 npm ci → release gate → TypeScript/Vite build → Pages artifact deploy를 수행합니다. 이번 작업에서 원격 GitHub 배포는 수행하지 않았습니다.


## 0.7.3 수정사항

- 근태 기간은 조회 버튼으로 적용합니다. 마감 대상은 조회 종료월이며 별도 마감월 입력은 없습니다.
- 입사일·퇴사일·휴직 유형·회사 지급비율·연금·건보·고용보험 처리 항목을 기존 근태 표에 표시합니다. 휴직 등록·수정은 WFM에서 합니다.
- 일용직 검색·조직·기간·조회는 한 줄, 확정·마감·신고 내보내기·목록/샘플 다운로드·목록 업로드는 한 줄에 배치했습니다. 신고·마감 대상은 조회 종료월입니다. 작은 화면에서는 줄바꿈합니다.
- 가상정보 안내는 상단 Build 문장 바로 아래 일반 텍스트로 표시합니다. 요청한 설명 배너와 재직상태 필터 칩을 제거했습니다.
- 2026-09 가상 급여는 검증→확정→근태 마감→급여 마감→지급 완료 상태로 저장됩니다. 기존 0.7.0 데이터에도 적용하며 지급된 월은 수정·재계산이 잠깁니다.
- 급여 설정에서 항목별 기본 산출식, 수정 산출식 또는 직원 공통 수기 금액을 확인·저장할 수 있습니다. 산출식은 사칙연산과 min/max/round/floor/ceil/floor10을 지원하며 저장된 계산식이 실제 급여 계산에 적용됩니다.
- 설정 변경 후 미확정 급여는 다시 계산해야 합니다. 확정·마감·지급 월의 계산 결과와 설정 스냅샷은 유지합니다. 개인별 보험·지방소득세 수기 입력과 휴직 고지·납부예외는 우선 적용됩니다.
- 기존 CSV/XLSX/JSON 근태 파일은 새로 추가된 읽기 전용 입사일·휴직 열이 없어도 가져올 수 있습니다. 휴직 설정은 WFM의 휴직 등록·수정에서 저장합니다.
- 회귀 검증: `npm run test:revision`, `npm run test:requested`, `npm run build`.


## 0.7.3 추가 변경

- 급여요약은 Payroll의 원천세 신고와 급여 설정 사이에 있습니다. 월별 지급 인원과 공제 항목을 연도별 표로 묶었습니다. 연간 인원 합계는 중복을 제외한 지급 대상 인원이며 금액 합계는 해당 연도의 월별 합산입니다.
- 근태와 급여의 첫 7열은 귀속월·지급일·사번·성명·팀·직급·입사일로 통일했습니다. 직급 열까지 왼쪽 열을 고정하며 근태·연차·일용직·급여 표는 같은 높이로 내부 스크롤합니다.
- 근태 표에는 휴직 유형·기간과 소정시간 미달·결근/병가·지각·조퇴 이슈를 표시합니다. 급여·보험 휴직 처리는 Payroll의 근태 조회에 표시합니다.
- 2025-01~2026-09 기본 가상 급여는 지급 완료입니다. 초기화는 신고자료 확정·일용직 마감·수기 자료를 지우고 기본 교육 데이터로 돌아갑니다. 과거 급여 지급 완료는 기본값으로 복구됩니다.
- 일용직 초기 조회 기간은 서울 날짜의 당월 1일~말일입니다. 미래 근무기록은 생성하지 않습니다. 일용직의 종료 여부는 근무종료일로 판단하고 상태 열은 표시하지 않습니다.
- 신고 내보내기는 제공받은 신고 원본 양식에 회사 전화번호와 일용직 근무자료를 채운 엑셀 파일 한 개만 다운로드합니다. 회사정보 JSON 추가 다운로드는 제거했습니다.
- 연간 그래프는 월말 재직 인원·월중 퇴사 인원과 지급액을 서로 다른 단위 축의 그래프로 분리합니다. 월간 그래프는 실제 저장된 일별 근태 분류를 사용합니다. 원 그래프는 당일 구성, 옆 표는 전일 대비 증감입니다. 일별 기록이 없는 날짜는 0명으로 추정하지 않습니다. 출근·병가·휴무 외 휴가/결근 등은 기타에 포함합니다. 연간 급여 지급액은 정규 Payroll의 지급 완료 실지급액입니다.

## 0.7.3 변경사항

- 모든 표의 열 정렬(▴/▾), 우클릭 숨기기, 열 필터 창. 급여 입력 필터는 급여월 생성 옆에 배치합니다.
- 급여·근태 조회는 당월 한 달이 기본값입니다. 급여 조회 조건·버튼의 높이를 44px로 통일했습니다.
- 급여요약은 화면의 현재 열 표시·행 정렬·연도별 구분·합계를 엑셀에 반영합니다. 인원 합계는 월별 인원의 합산입니다. 자동 다운로드가 제한된 브라우저에서는 생성 후 표시되는 `급여요약.xlsx 저장` 링크를 사용할 수 있습니다.
- 646개 구간의 공식 간이세액표와 지급월별 자녀 공제로 가상 급여 소득세를 채웁니다. 기존 자료에서는 손대지 않은 자동 생성 더미 급여만 갱신합니다. 개인별 수기 수정 자료와 지급 완료 잠금은 유지합니다.
- 새 교육환경은 입·퇴사 시점, 계절 수당·상여, 일용직 근무 횟수가 월별로 달라집니다. 기존 직원 원장의 입·퇴사일은 보존합니다. 새 인원 시나리오는 교육환경 초기화로 생성됩니다.
- 적용기준 역전 배지를 없앴습니다. 연차 적용기준은 계속 표시합니다.
- 연간 그래프는 좌우, 월간 인원·급여 그래프는 위아래로 배치합니다. 날짜 축은 말일까지 표시하며 미래 관측값을 생성하지 않습니다. 인원 막대의 합계와 출근·병가·휴무의 전일 증감은 월별 표에서 확인합니다. 급여 그래프는 정규직 지급일의 실지급액과 일용직 근무일 기준 금액이며, 수당은 계산 결과에 반영된 기본급 외 지급항목을 합산합니다.
- 채용 모듈 사용·연동 방법은 `src/modules/recruiting/README.md`를 참고하세요. 웹훅 전달 완료는 문자 배달 완료가 아닙니다. 실제 Notion·문자·캘린더 연결은 외부 자동화 서버의 설정이 필요합니다.
