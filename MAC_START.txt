HR Training Simulator 0.6.3 — macOS 실행

1. ZIP을 압축 해제합니다.
2. 터미널에서 압축을 푼 hr-training-simulator-v0.6.3 폴더로 이동합니다.
3. 아래 두 명령을 실행합니다. Node.js 22 이상이 필요합니다.

npm install
npm run dev

기본 주소: http://127.0.0.1:5173
초록색 안내는 제거했습니다. 작은 Build 표기와 브라우저 제목에 0.6.3가 표시됩니다.
시작 전에 메뉴·버전·파일 재입력·데이터 저장 자동검증을 실행합니다.

기존 실습 데이터는 같은 브라우저, 주소, 포트에서 유지됩니다.
다른 프로그램이 5173을 사용하면 임의 종료하지 않고 실행을 중단합니다.
별도 테스트 포트가 필요한 경우만 HR_PORT=5187 npm run dev를 사용할 수 있습니다.
테스트 포트는 기존 데이터와 별개의 원장입니다.

각 화면의 조회 목록 다운로드 → XLSX/JSON 선택 → 입력값 수정 → 수정 파일 업로드로 반영합니다.
사번/번호·개인·기간을 유지하세요. 합계·잔여·상태는 원자료에서 계산합니다.
근태 수정 후에는 근태 수당 반영과 급여 계산·검증을 다시 진행하세요.
