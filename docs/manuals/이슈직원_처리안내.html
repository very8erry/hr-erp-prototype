처음 확인할 원본

근태 조회 → 기타메모참조 → 일별 상태·유급/무급·사유·증빙 → 휴직 기간·회사 지급비율 → 급여 원천과 결과. 정상 표시는 별도 검토 사유가 없다는 뜻이다. 유급휴가 메모가 있다고 오류는 아니다.

시간과 차감

계약 소정시간은 달력별 계획, 209는 통상임금 환산시간이다. 실근로·유급인정·지원금 구간을 구분한다. 결근시간과 소정시간 미달을 두 번 차감하지 않는다. 야간·연장 가산시간을 이중 합산하지 않는다.

원본 수정 이후

미확정이면 사유를 남겨 근태를 수정하고 월 합계 적용 → 근태 수당 반영 → 계산 및 자동 검증. 확정/마감 미지급이면 정정·이력에서 원본 보존 후 잠금 해제. 지급 완료는 이후월 차액 반영만 가능하다.

사례 식별

기본 생성 사례의 이름은 기존 저장본에 따라 달라질 수 있다. 아래 고용ID·날짜·원본 사유를 함께 확인한다. 사용자 수기 이름·증빙을 재구성 과정에서 바꾸지 않는다.
