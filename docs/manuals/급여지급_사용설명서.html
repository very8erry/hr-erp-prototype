업무 시작점

공지게시판·취업규칙 원문 확인 → 급여 설정의 규정 기준표 대조 → 회사정보·직원 등록 → 근로계약·보험·가족정보 확인 → 근태 입력 → 급여월 생성 → 근태 수당 반영 → 급여 계산 및 자동 검증 → 오류 정정·경고 확인 → 확정 → 근태 마감 → 급여 마감 → 실제 지급 확인 후 지급 완료 → 신고자료 작성.

기존 설명서에서 바뀐 점

별도 검증 버튼은 제거됐다. 계산할 때 오류·경고를 함께 확인한다. 정정·이력에서 미지급 확정/마감을 해제하거나 지급 이후 차액을 반영할 수 있다. 초기화는 전체 또는 월·업무 범위를 선택한다.

데이터 보존

동일 브라우저·주소·포트의 IndexedDB를 사용한다. 브라우저나 주소가 달라지면 별도의 저장소다. 작업 전 전체 JSON 백업을 내려받는다. 문서나 공개 사이트 배포가 사용자 로컬 자료를 서버로 전송하지 않는다.

상태와 실제 지급

지급 완료는 앱 내부 기록이다. 은행 이체를 실행하지 않는다. 파일 다운로드 역시 국세청·공단의 접수가 아니다. 실제 지급·접수·납부 증빙은 담당자가 대조한다.

규정 확인과 인사등록

규정 기준표

급여 → 급여 설정 → 규정 기준표. 문서별 원문·첨부 읽고 기준 추출을 누른 뒤 근거 조항·시행일·대상·단위를 검토한다. 숫자를 찾을 수 없는 조항은 임의 기본값으로 채우지 않는다. 일치/불일치/확인 필요/미연결/적용 제외를 구분한다.

실제 설정으로 이동

원천 설정 열기는 근로시간의 경우 직원 근로계약, 지급일은 기본 지급일, 운영규칙은 업무일정 설정으로 연결된다. 저장 후 기준표를 다시 대조한다. Markdown 다운로드는 화면과 같은 비교 결과다.

직원 등록·검토

직원 관리 → 직원 등록에서 사번·성명·생년월일·입사일·조직·연봉 등을 입력한다. 사번 중복과 이름 검토, 공지 기준과 다른 소정시간 재검토 안내를 확인한다. 이름만으로 동일 인물을 병합하지 않는다.

유효기간 근로계약

직원 상세 → 근태설정 → 근로계약에서 근무요일, 시업·종업·휴게, 주휴일·주휴시간, 통상임금 월 환산시간, 단축 유형과 사유를 저장한다. 새 계약은 기존 이력의 종료일을 조정하여 보존한다. 확정·마감·지급된 기간은 정정 절차가 먼저다.

209시간의 의미

주40시간과 유급 주휴8시간의 평균 월 환산시간이 209시간이다. 달력상 실제 근무시간을 매월 209시간으로 맞추는 값이 아니다. 실제 소정시간은 계약 근무일과 공휴일·입퇴사·단축기간으로 계산한다.

근태 원천과 급여 연결

월 조회와 일별 원본

근태 → 근태 조회에서 기간과 이름·팀을 조회한다. 상태(이슈포함)의 기타메모참조로 유급/무급 사유와 증빙을 확인한다. 일별 캘린더에서 근무·휴가·휴게·메모·파일을 수정한 후 월 합계를 적용한다.

시간을 분리해서 검토

소정시간·실근로·연장·야간·휴일·유급연차·기타인정·유급주휴·공휴일을 구분한다. 야간은 실근로에 겹치는 가산시간이므로 두 번 실근로에 더하지 않는다. 연장이나 휴일근로가 다른 날 결근을 상쇄하지 않는다.

주휴와 미입력

15시간 기준, 계약 주휴일, 해당 주 근무기록과 결근을 대조한다. 경계 주 기록이 없거나 지원금 구간이면 확인 필요로 남는다. 자동 산출되지 않은 시간을 임의로 유급 확정하지 않는다.

급여 수당 반영

급여월의 근태 수당 반영을 실행하면 연장·야간·휴일 원본을 연결한다. 이후 계산은 최신 근태시간과 같은 버전·계약 기준을 함께 저장한다. 계약 변경월의 기본 수당은 날짜별 계약 환산시간과 육아기 단축 지급비율을 나누어 적용하며 상세의 계약별 단가에서 확인한다. 여러 단가에 걸친 사용자 산출식은 적용 단위 검토 전 확정할 수 없다. 급여 개인 상세의 근태 기준과 수당 옆 시간을 대사한다. 수기 금액 방식을 선택한 직원은 시간을 자동 덮어쓰지 않는다.

HR 업무 예상시간

업무일정의 예상작업시간은 담당자의 업무계획이다. 직원의 출퇴근 근태나 급여 계산 시간에 포함되지 않는다.

급여설정·정산·자동 검증

가산율·보험요율 승인

급여 설정 → 급여 산출기준 → 가산율·보험요율 기준에서 귀속월의 실제 계산값과 공식 원문 후보를 본다. 원문 검토·승인에서 키워드·값·단위·시행기간을 확인하고 승인한다. 승인 전에는 기존 설정값, 승인 후에는 해당 기간 승인값이 적용된다.

공통 고정금액

항목별 확인·수기 수정에서 기본 산출식/사용자 지정 산출식/공통 고정금액을 구분한다. 공통값은 대상 직원과 지급요건·시행월을 지정한다. 직원별 명시 금액은 0원도 우선하며 공통값과 합산하지 않는다. 보험 공제·근로시간 수당은 공통 고정금액 대상으로 두지 않는다.

비과세·보험 교차검증

예: 지급요건을 충족한 식대 30만원은 인정 비과세 20만원, 과세 초과 10만원으로 나뉜다. 초과분은 항목의 보험 포함 설정에 따라 후보액으로 계산한다. 연금·건보 결정 보수를 자동 교체하지 않는다. 고용보험 보수 계산 연동 여부를 별도로 확인한다.

개별 정산항목

정산항목에서 사용·표시·중도 포함·연말 차수를 개별 선택한다. 세금/보험 쌍의 공통 조건만 같이 적용할 수 있다. 개인 급여 입력의 정산 반영에 실제 확정 금액과 사유를 넣는다. 추징은 양수, 환급은 음수다.

계산 한 번으로 검증

급여 계산은 금액과 오류·경고를 함께 갱신한다. 오류 없는 VALIDATED만 확정할 수 있다. 경고는 직원별 확인 대상이며 정상 상여·휴직 변동을 무조건 오류로 만들지 않는다. 원천을 정정하면 다시 계산한다.

확정·마감·지급 후 정정

정상 지급 순서

계산 및 자동 검증 → 오류 해결·경고 확인 → 확정 → 같은 월 근태 마감 확인 → 급여 마감 → 실제 지급 후 지급 완료. 총지급 - 총공제 = 실지급과 수당 시간·단가·배율을 확인한다.

확정·마감 상태, 아직 미지급

급여월 → 정정·이력. 사유를 입력하고 미지급 여부와 신고 영향을 확인한다. 필요하면 근태 잠금도 함께 해제한다. 원본 입력·결과·상태를 로그에 보존한 후 DRAFT로 되돌린다. 정정 후 계산·확정·마감은 다시 해야 한다.

지급 완료 상태

원본을 직접 수정하지 않는다. 정정·이력에서 직원·이후 미확정 반영월·원본 항목·정정 구분·전후 금액·사유를 지정한다. 추가 지급은 소급금, 환수는 별도 공제, 분류 정정은 과세/비과세 이동으로 기록한다. 같은 원본 항목 정정의 중복 적용은 차단된다.

차액과 실지급의 구분

항목 차액은 세전 또는 분류 차액이며 통장 추가 입금액과 같지 않다. 반영월 세금·공제 계산 후 전체 실지급을 확인한다. 분류 정정은 총지급을 늘리지 않는다. 원신고·보험·퇴직·연말정산의 정정 여부는 원본과 별도 검토해야 한다.

원본 내역 출력

급여 조회 또는 급여월의 개인 상세 → 개인 내역 다운로드 → CSV/XLSX/JSON. 저장된 결과·수당 시간·근태 기준을 확인한다. 이 경로는 개인 내역 다운로드이며 법정 명세서 자동 교부·이메일 전송을 의미하지 않는다.

신고자료와 백업·초기화

원천세·위택스·공단

급여 → 원천세 신고에서 홈택스·위택스 자료를 구분한다. 원천징수이행상황신고서 작성값을 검토하고 PDF 다운로드한다. 4대보험 신고는 별도 메뉴에서 기관별 자격·보수 자료를 확인한다. 제출 규격·실제 식별정보와 접수 결과는 기관에서 검토한다.

근로소득간이지급명세서

급여 → 근로소득간이지급명세서 → 지급연도/반기 → 지급자료 불러오기. 지급완료 원본·회사정보·과세소득·거주 구분을 확인한다. 2026은 반기 제출이다. 12월 말 미지급 의제를 선택하면 확정/마감 미지급을 별도 포함한다. 다음 해 지급한 전년도 소득의 중복 집계를 피한다.

다운로드·업로드

작성목록은 Excel/CSV/JSON, 공식 양식 작성은 2026 반기 PDF를 제공한다. 인정상여는 일반 상여와 다른 항목이다. 샘플과 업로드는 동일 열을 사용하며 직원/가상식별번호가 다르면 거부한다. 초안 저장은 이전 버전을 보존한다. 2027 월별 목록은 제공하지만 새 공식 PDF 양식은 아직 지원하지 않는다.

범위 선택 초기화

상단 초기화에서 전체 백업을 내려받고 범위를 고른다. 월 급여, 월 근태와 급여, 일용직 확정·마감 상태, 전체 교육환경을 구분한다. 연결 신고 초안의 영향 범위도 함께 확인한다.

규정 기준 더미 재구성

전체 백업 후 시작/종료월을 선택한다. 기본 가상회사·생성 기록만 대상으로 하며 수기·출처불명·가져온 자료는 제외한다. 기존 사람·고용·사례를 유지하고 계약·달력으로 재집계한다. 재구성 급여는 검증 완료·미확정으로 남으며 자동 지급완료로 복구하지 않는다.
