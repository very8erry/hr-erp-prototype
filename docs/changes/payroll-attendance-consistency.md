# 근태 연동 급여 검증 수정

기준: main b4aeb300270a62273d3d5f0c2fea87f2a09ba800. 작업 브랜치: codex/payroll-attendance-consistency.

## 결함과 변경

원천 근태의 연장시간을 2→10으로 수정한 뒤 검증하면, 기존 calculationInputs의 2시간으로 계산하고 최신 attendanceRevision을 저장했다. 수정 전 회귀 테스트는 실제 2, 기대 10으로 실패했다.

근태 연동 항목은 계산 트랜잭션 안에서 최신 월 집계와 일별 휴일 초과시간을 읽는다. 입력·결과·근태 버전·검증 상태·감사로그를 함께 저장한다. 확정도 원본 시간과 버전을 확인하는 트랜잭션으로 처리한다. 원본이 없으면 전체 작업을 취소한다. 수기 금액 방식과 확정·마감·지급 결과는 유지한다. 기존 DB의 식별자·스키마·데이터를 일괄 수정하지 않는다.

240,000원은 통상시급 20,000원 × (10−2)시간 × 1.5배의 예시이며, 모든 직원의 차액이 동일한 것은 아니다.

근태 불러오기 역시 급여 산출 함수를 사용해 설정 배율·월 소정시간을 반영한다. 급여 상세에는 산출 수당 옆에 계산시간을 표시한다. 산출기준 수정창에는 가산율 변수의 저장 위치와 기본 배율을 표시한다.

연차 탭을 근태에 통합한다. 필터 여백을 줄이고 급여월·지급일·저장 버튼을 정렬한다. 회사설립일은 이미 구현돼 있어 기존 입력란과 저장을 유지하고 회귀 테스트로 검증했다.

## 적용 범위

main 병합 및 배포하지 않았다. 과거 확정·마감·지급 결과를 자동 보정하지 않는다. 미확정 급여는 다시 검증하면 최신 근태가 반영된다. 연동시간 수정은 근태 원본에서 하고, 수기 금액은 연동을 해제해서 입력한다.
