- 모든 페이지의 4쪽 모아보기 이미지를 시각 검토했다. 도식과 발견된 레이아웃 문제는 개별 페이지 또는 원본 도식 이미지로 확대 재검토했다.

- 최종 `pdfplumber` 검사: 페이지 밖 문자 0, 빈 페이지 0. 한글 텍스트 추출 가능, PDF 작성자 `HRIS Analysis`. 일반 본문/목차/페이지 번호 및 도식의 주요 라벨이 보인다.
- 목차는 실제 ReportLab multiBuild 결과로 생성했다. 본문의 13개 문서 제목과 11개 도식 페이지에 대응한다. ERD는 두 상세도로 분할했다.
