# v0.7.8 · 요청사항 반영

## 업무일정과 대시보드
- 모든 분야에서는 직원이슈·안전보건·채용 등 큰 주제만 표시합니다. 날짜를 누르면 그 날짜에 해당하는 적용업무표를 표시합니다.
- 적용업무표에서 같은 업무의 여러 단계는 한 행에 묶었습니다. 제목·기간·대상·원본이 같은 반복 표시를 제거하며 원본 기록을 삭제하지 않습니다.
- 안전보건관리규정, 안전보건 경영방침, MSDS는 원본 문서와 해야 할 일이 달라 별도 업무로 유지합니다. 공통 게시 위치·담당자 점검은 안전보건 문서 자체의 승인·서명과 구분됩니다. 상세 업무의 반복 표시를 합치고 큰 주제로 묶었습니다.
- ‘적용 범위·누락 방지 분류’ 삭제. 기존 변경안/기획예시/촉진 버튼은 업무일정에 표시하지 않습니다.
- 월별업무표는 달력형 및 리스트형 XLSX로 다운로드합니다. 현재 조회 조건을 적용합니다.
- 대시보드에서 회사일정과 업무일정을 전환합니다. 회사일정에는 HR 업무가 섞이지 않습니다. 회사에 등록한 일정과 11월 5일 창립기념일은 회사·업무·대시보드 달력에 연결됩니다. 창립기념일은 자동 유급휴일로 판정하지 않습니다.

## 회사정보와 직원정보
- 회사정보에서 기능설정·보험구분·이직사유 기본값·고지 근거/출처 입력란 제거.
- 회사 공용 이메일 lemonpai314@lemonpai314.com, 기존 직원 이메일 도메인 @lemonpai314.com 반영. 1회 마이그레이션으로 적용하고 이후 수정값은 보존합니다.
- 직원관리 → 정보수정 → 보험자격에서 이직사유 코드·구체적 사유를 입력하고, 고용정보에서 확인합니다. 상실·이직 입력자료 자동 불러오기에 연결됩니다.
- 직원 직종은 개인 수동 지정 → 팀·직무 매핑 → 회사 기본 코드 순서로 적용합니다. 회사정보의 직종코드 표 2개는 가로·세로 스크롤로 전체 열을 확인합니다.
- 업무 사이트 메뉴 아래 기존 인사 업무 사이트와 정부24·공정거래위원회·중소벤처기업부·KISA 보호나라 링크를 제공합니다.
- 산재 기본요율은 정보처리·소프트웨어(90701) 0.60%와 출퇴근재해 0.06%를 합한 0.66%입니다. 사업주 추가 고용보험은 우선지원 대상이 아닌 150~999명 기업 조건의 0.65%를 기본으로 입력했습니다. 개별실적 요율과 회사 규모·우선지원 여부가 달라지면 회사정보에서 조정합니다. 근로자 급여 공제율과 별도입니다.
- 직원정보수정·인사발령등록·이름검토수정 아이콘을 같은 높이·간격으로 배치하고 가상식별번호 기준 아이콘 추가.
- 상단의 이력서 원본 파일 선택란 제거. 첨부문서 탭에 이력서 원본 표와 업로드·다운로드를 배치했습니다. 새 더미 이력서는 생성하지 않습니다.

## 메뉴·로그·공지·채용·필터
- 사이드바 명칭 ‘인사 실습･검토 시스템’, 하단 ‘교육용’ 문구 제거, 확장모듈 보상 제거.
- ‘감사로그’ → ‘로그’. 건당 한 줄 가로 표, 긴 값은 마우스 올리기로 전체 확인.
- 공지게시판은 회사정보 탭으로 이동. 게시 상태 → 제목 → 작성팀 → 게시일 → 첨부 건수 순서의 한 줄 목록.
- 채용에서 자동화 연동·오퍼 입사전환 메뉴 제거(기존 저장자료 보존). 평가의 현재 사용자·작업역할·작성평가자 입력란 및 안내문 제거. 서류평가·면접평가 옆에 지원부분 선택 배치.
- 필터의 고정 열 폭을 없애고 항목 텍스트가 끝난 다음부터 다음 열까지 1cm 간격을 둡니다.
- 삭제·제거 동작에는 대상 확인 팝업을 적용했습니다. 이미 확인 절차가 있던 동작은 기존 확인을 유지합니다. 취소 시 자료가 변경되지 않습니다.
- 좁은 창에서 팝업 하단 동작이 잘리지 않도록 줄바꿈 및 버튼 정렬 보완.

## 근태·급여·신고
- 연차조회에 연차촉진 버튼: 개인 원장·일반/1년 미만/추가발생·소멸일을 선택하고 1차 서면 촉구, 수령·회신, 미회신자 2차 시기 지정, 사용·잔여·예외 검토와 증빙을 관리합니다. 기존 기록이 있으면 열어 이어서 관리합니다. 근로기준법 제61조 기준이며 일괄 ‘연 2회’로 고정하지 않습니다.
- 급여요약의 연도 표시는 현재 한국 날짜 기준 당해년도(2026)·전년도(2025)로 매년 바뀝니다.
- 개인별 보험료의 신고처 링크는 샘플 다운로드 오른쪽 홈페이지 아이콘으로 변경.
- 통합 취득·상실은 건강보험 EDI 공식 샘플의 39열·22열 순서와 일치합니다. 화면·입력샘플·가져오기·내보내기를 공통 스키마로 관리합니다. 신고용 XLSX에는 안내·제목 행이 없고 데이터만 있습니다. 입력샘플에는 열 이름이 있으며 샘플에 입력한 파일과 데이터만 있는 파일 모두 업로드 가능합니다.
- 선택월 입사자/퇴사자를 자동 불러옵니다. 주민번호는 생성하지 않으며 확인되지 않은 취득부호·상실부호·신고보수 등은 직접 입력합니다. 식별번호·공단구분·날짜·필수 항목·500명 제한을 검사하고 검증되지 않은 파일은 신고용으로 내보내지 않습니다.
- 이는 건강보험 EDI의 ‘4대 전체신청’ 파일송신 구조에 맞춘 파일입니다. 다른 포털의 서로 다른 업로드 양식까지 공통으로 보장하지 않으며, 인증된 실제 사업장 계정에서의 접수는 수행하지 않았습니다. 가상 정보로 실제 신고하지 마세요.
- 보수총액은 2025.7.1 개정 별지 제22호의4 기준 한글 항목으로 구성했습니다. 산재·고용 보수를 구분하고 일용/기타 합계 입력란을 제공합니다. 연간 생성된 급여에서 과세보수를 불러오되 휴직자의 산재 제외보수는 미확인 값으로 남깁니다. 전보·종사지 우편번호·특수 대상은 실제 근거를 확인해 보완해야 하는 검토 입력자료이며 공단 전자접수 파일로 검증된 양식은 아닙니다.
- 원천징수 신고서 작성값은 원본 배경에 맞춰 한국어 글꼴까지 이미지로 포함하는 A4 PDF로 저장합니다. 원본은 국가법령정보센터의 2026.5.22 개정 서식 전체 10쪽 PDF를 제공합니다. 작성값 PDF는 주 신고서 1쪽이며 원본의 모든 부속·환급신청서 자동 작성은 포함하지 않습니다.
