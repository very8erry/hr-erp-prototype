# HR Training Simulator v0.7.1

실행: 압축을 푼 폴더에서 `npm install` → `npm run dev`.
검증: `npm run build`. 화면 실행은 `npm run dev`입니다.

수정사항과 계산 적용 방식은 README.md의 0.7.1 수정사항을 확인하세요.

요청한 설명 문구는 시스템 화면에서 제거했습니다. 일용직 지급·원천징수는 정규직과 별도로 계산하고, 통합 급여 요약에서 월별 합산할 수 있습니다. 수정 산출식·수기 금액은 급여 항목 설정에 저장되며 미확정 급여를 재계산하면 반영됩니다.

신고 예시 엑셀은 원본 양식 복사본에 더미 데이터만 채웠으며 회사 전화번호를 사용합니다.
