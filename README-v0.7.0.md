# HR Training Simulator v0.7.0

기존 v0.6.3 프로젝트를 수정한 전체 프로젝트입니다.

## 실행

Node.js 설치 후 이 폴더에서 `npm ci`, `npm run dev`를 실행합니다. 기존 실행 서버는 종료하고 새 폴더에서 실행하세요. `npm run build`는 기존 회귀검증 후 프로덕션 파일을 만듭니다. 추가 기능 검증은 `npm run test:requested`입니다. 첫 실행 시 21개월 자료 생성에 약 30~60초가 걸립니다.

## 반영 내용

- 회사정보 입력·저장 및 백업 보존, 회사 대표전화 신고서 반영
- 급여설정 급여/4대보험/원천세 분리 및 정산항목 표시·중도 포함·연말 분납 설정 저장
- 원천세 신고 명칭 및 원천징수이행상황신고자료 대사 통일
- 월 전체 근태 마감 후 급여 마감 허용, 저장 계층에서 수정·추가 차단
- 일용직 기간 설정 후 조회, 조회 범위 신고자료 확정, 귀속월 전체 확정 후 마감
- 통합 월별 정규직/일용직 지급 요약
- 2025.01~2026.09 가상 급여·근태·일용직 자료, 서울 날짜까지 2026.10 일별 근태 누적
- 앱 재실행 및 앱이 열린 상태의 날짜 변경 시 10월 일별 근태 추가, 미래 날짜 제외
- 근태 내보내기/가져오기 명칭 변경, CSV/XLSX/JSON 유지
- 대량 근태/일용직 자료 100건 페이지 표시, 파일·합계는 전체 조회결과
- 입사일/회계연도 누적 발생 예상 비교, 회사기준 선택 및 역전 배지

## 신고용 엑셀

`public/work-report-template.xlsx`는 사용자가 올린 원본입니다. 원본의 서식 시트(A~BB) 데이터 행만 채우며 나머지 파일 구성요소·안내·작성예시·코드 안내·유효성검사를 그대로 보존합니다. 월 전체 일용 근무자료를 개인별 합산하고 근무일에는 1을 기재합니다. 귀속월별로 생성하며 지급월은 같은 월 지급을 가정합니다.

원본에는 회사명·사업자번호·사업장관리번호 전용 칸이 없습니다. 따라서 임의 열을 추가하지 않고 회사 식별정보는 함께 내려받는 JSON에 기록하며 F/G/H의 전화번호는 회사 전화번호로 채웁니다. 보험구분·이직사유 기본값 및 직종코드를 회사정보에서 관리합니다. 가상 직무에 대해서는 KECO 2025 코드(사무보조/데이터정리 029, 행사보조 617, 매장지원 616, 물류지원 624)를 사용합니다. 주민등록번호는 의도적으로 무효인 13자리 더미값입니다. 실습 파일로 실제 제출용 개인정보가 포함되지 않습니다. 국적은 국내 가상근로자 기준 100, 체류자격은 공란입니다.

작성안내의 1일 10만원 공제 문구는 원본 그대로 보존하지만 계산은 국세청 현행 일용직 15만원 공제 기준을 사용합니다.

## 연차/정산의 적용 범위

연차 비교는 첫해 개근·이후 80% 이상 출근을 전제로 한 누적 발생 예상치입니다. 실제 출근율·휴직 출근간주·사용·소멸·퇴직 정산은 저장 연차 원장에서 검토합니다. 회계연도 첫해는 재직일 비례, 이후 1월 1일 일괄 부여하는 가상 회사규칙입니다. 두 기준 중 유리한 값을 적용하거나 회사정보에서 입사일 기준을 선택할 수 있습니다.

정산항목 포함·분납 설정은 저장되는 운영 설정이며 실제 정산 세액의 자동계산/분납 이체는 하지 않습니다. 정산금액은 기존 연말/퇴직정산 화면에서 검토·수기 입력합니다. 급여항목의 최초 체크는 가상 회사의 고정 현금수당 조건을 전제로 한 기본 분류이며 실제 회사 지급조건에 따라 수정합니다. 월급 소득세는 기존 수기 입력/검토 방식입니다.
